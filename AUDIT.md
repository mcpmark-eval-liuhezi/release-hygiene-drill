# Release hygiene checklist (short version)

1. **Reviewer coverage** — confirm the release pull request has at least one qualified reviewer (see issue #2).
2. **Leaked secrets** — confirm the repository has no open secret-scanning alerts (see issue #3).
3. **Branch freshness** — update the pull request branch with the default branch before merging.
4. **Sub-issue tracking** — keep the checklist tracking issue (issue #1) in sync with what is and isn't still tracked there.

This is drill material only.
